# 论文写作检查清单

## Chapter 1 Introduction

- [ ] 解释困境反转、横盘突破和成交量确认为什么值得研究。
- [ ] 明确研究问题是相关性，不是因果识别。
- [ ] 用一段话说明A股和沪深300的样本背景。
- [ ] 列出研究贡献，不夸大交易可执行性。

## Chapter 2 Literature Review

- [ ] 每个核心论点都有真实、可核实的论文来源。
- [ ] 区分价格反转、技术突破、成交量信息和A股制度背景。
- [ ] 说明现有研究没有直接回答的具体缺口。
- [ ] 不把本项目结果当作文献依据。

## Chapter 3 Data and Methodology

- [ ] 写明193个事件、160只股票和日期范围。
- [ ] 写明股票池、ST、停牌和冷却限制。
- [ ] 写明30%困境、120–252日横盘、25%带宽、趋势限制和0.5%突破。
- [ ] 写明RVOL、收益和控制变量公式。
- [ ] 写明OLS+HC3和Logit的用途及限制。

## Chapter 4 Results

- [ ] 报告描述统计后再报告模型结果。
- [ ] 每个系数同时报告样本量、标准误或p值、R²。
- [ ] 区分简单模型与控制模型。
- [ ] 不把10%显著写成强证据。
- [ ] 不把相关性写成因果关系。

## Chapter 5 Robustness

- [ ] 说明每项检验只改变哪个定义。
- [ ] 说明阈值变化会生成不同事件池。
- [ ] 披露成交量窗口结果的显著性并不完全一致。
- [ ] 披露Failure60只有14个完整非失败样本。

## Chapter 6–7 Discussion and Conclusion

- [ ] 解释结果可能机制时使用“可能”“与……一致”，不用“证明”“导致”。
- [ ] 披露聚类标准误、市场状态、行业历史和执行时点限制。
- [ ] 结论直接回答研究问题，不引入新结果。
