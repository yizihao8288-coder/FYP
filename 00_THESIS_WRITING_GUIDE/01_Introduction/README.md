# Chapter 1 Introduction

## 这一章要回答什么

这一章要让读者明白：为什么在经历大幅下跌和长期横盘后，向上突破当天的成交量可能包含信息，以及为什么需要在A股大市值股票中检验这一问题。

## 研究逻辑

常见技术分析叙述把“放量突破”视为更可靠的信号。但异常成交量也可能代表拥挤交易、短期情绪释放或卖压集中出现，因此未来收益方向不能只靠直觉判断。本研究用历史事件检验这两种可能，而不是预先假设放量一定是好消息。

## 可以这样安排正文

1. 说明困境反转的经济背景：股票先经历明显下跌，再进入价格收敛阶段。
2. 说明突破的判断问题：价格越过阻力位是否代表趋势真正反转。
3. 引入成交量：成交量可能反映交易参与度和信息到达，但方向不确定。
4. 提出主问题：`ln_RVOL`是否与R20、R60及突破失败风险相关。
5. 说明研究贡献：历史沪深300股票池、明确事件定义、多种突破和成交量窗口稳健性、失败概率补充分析。

## 当前研究问题

在沪深300历史成分股的技术性困境反转突破事件中，突破日异常成交量`ln_RVOL`是否与未来收益和突破失败风险系统相关？

## 不应怎样写

- 不要写“本研究证明高成交量导致未来下跌”。
- 不要写“该策略能够在突破日收盘价获利”。事件日收盘和成交量在收盘后才完整可知。
- 不要声称样本代表全部A股。本研究对象是经过数据质量筛选的沪深300历史成分股事件。
