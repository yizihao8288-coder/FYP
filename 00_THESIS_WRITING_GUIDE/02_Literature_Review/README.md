## 建议的四个文献板块

### 2.1 困境、超跌与反转

解释大幅下跌之后可能出现均值回归，也可能继续恶化。需要区分基本面困境反转与纯技术价格反转。

### 2.2 横盘、阻力位与价格突破

讨论横盘如何表示价格收敛、阻力位如何定义，以及突破信号为什么可能包含价格发现信息或噪声。

### 2.3 成交量与价格信息

讨论成交量是否代表信息到达、投资者分歧、流动性、注意力或交易拥挤。这里是`RVOL`理论解释的核心。

### 2.4 A股市场制度背景

讨论涨跌停、停牌、ST制度、散户参与和状态依赖为什么可能使海外结论不能直接套用。

## 文献综述的逻辑

每一小节都应按照“已有研究发现什么—使用什么方法—结论有什么限制—本研究如何接着做”展开。研究缺口应具体到：现有研究是否同时结合了大幅下跌、长横盘、向上突破、异常成交量和多个未来窗口。
