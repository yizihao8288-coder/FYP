# 5.3 Volume Window Robustness

## 检查什么

baseline用过去60个有效交易观察计算平均成交量。这一小节改用20日和120日，检查核心结论是否依赖60日窗口。

## 方法

- `RVOL20 = 突破日成交量 / 过去20个正常正成交量观察均值`
- `RVOL60 = 突破日成交量 / 过去60个正常正成交量观察均值`
- `RVOL120 = 突破日成交量 / 过去120个正常正成交量观察均值`

每个版本分别取自然对数并运行相同的R20 Model 2。

## 主要结果

| 窗口 | `ln_RVOL`系数 | p值 |
|---|---:|---:|
| 20日 | -0.0137 | 0.3054 |
| 60日 | -0.0237 | 0.0985 |
| 120日 | -0.0298 | 0.0388 |

三个系数方向都为负，但20日结果不显著，120日更强。这说明方向较稳定，但统计精度依赖成交量基准窗口。
