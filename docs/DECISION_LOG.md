# Decision Log

本文件记录“为什么这样做”。它不同于代码注释：代码说明如何计算，Decision Log说明为什么采用这个研究选择，以及何时允许重新评估。

| ID | 决策 | 理由 | 代价或风险 | 可否改变 |
|---|---|---|---|---|
| ADR001 | 股票池采用事件日前一交易日的沪深300历史成分 | 降低用当前成分回填造成的幸存者偏差 | 依赖历史成员快照完整性 | 仅在取得更权威历史成员数据后复核 |
| ADR002 | 技术性困境阈值为相对前高下跌至少30% | 形成足够明确的困境状态，同时保留可分析样本 | 突破日不一定仍比峰值低30% | baseline不改；替代阈值只能作为稳健性 |
| ADR003 | 横盘使用120–252日自适应窗口 | 允许不同股票形成不同长度的底部 | 252日上限堆积和扩展阶段趋势约束仍是限制 | baseline不改；未来版本另建 |
| ADR004 | baseline突破阈值为横盘高点上方0.5% | 在噪声过滤和样本量之间取平衡 | 固定百分比不能随股票波动率变化 | 1%、2%、ATR20仅作稳健性 |
| ADR005 | 核心RVOL窗口为过去60个正常正成交量观察 | 比20日稳定、又比120日更贴近近期 | 停牌股票的日历跨度可能超过60日 | RVOL20/120已单独比较 |
| ADR006 | baseline回归使用OLS + HC3 | 处理异方差并保持当前实证规格一致 | 不处理同股或共同日期相关 | 下一阶段增加聚类标准误，不替换baseline |
| ADR007 | 采用私有GitHub + D盘DataVault双通道 | 同时满足版本管理、数据许可和大文件保存 | 需要维护manifest并另接云同步 | 数据版本显著增加时再考虑DVC |
| ADR008 | 不删除、不winsorize异常值 | 保持原样本并避免结果导向处理 | 小样本估计可能受极端事件影响 | 可做透明的敏感性分析，但不能替代原结果 |
| ADR009 | close-based突破不解释为可在同一收盘价成交 | 当日收盘和成交量只有收盘后才完整可知 | 论文不能把事件收益直接写成无摩擦策略收益 | 可在未来构造次日开盘执行版本 |
| ADR010 | GitHub仓库按用户决定保持Public | 便于直接浏览、分享和管理研究档案 | 代码、论文结果、hash清单和部分本机路径记录对外可见；原始行情与冻结CSV仍不上传 | 答辩或数据许可要求变化时重新评估 |

完整机器可读版本见`catalog/decisions.csv`。新增决策必须使用新的ADR编号，不能改写旧编号来隐藏研究变化。
