# Variable Audit

## Existing Result

### 核心变量 ln_RVOL

公式：`ln_RVOL = ln(Volume_t / mean(Volume over previous 60 normal positive-volume observations))`。事件日不进入均值，因此没有把未来成交量直接泄露进解释变量。当前193个事件的RVOL均为正，取对数合法。

但“过去60日”在代码层面准确含义是过去60个有效、正常、正成交量观察；停牌会令日历跨度更长。论文应使用这个精确表述。

### 控制变量

- `Drawdown`：横盘内最低收盘相对横盘前252市场日峰值的跌幅。
- `Duration`：自适应横盘市场日长度，范围120–252；46个事件在上限处，存在右删失/堆积。
- `BreakoutStrength`：事件收盘相对横盘最高收盘的超越幅度。

这三个控制变量与事件算法直接相关，能降低机械定义差异，但不足以覆盖风险、市场状态和公司异质性。

## Potential Improvement

- 缺少事件前波动率/ATR、规模、估值、流动性、行业与年份或市场状态控制。
- `BreakoutStrength`和事件筛选阈值存在机械截断，且可能与`ln_RVOL`共同反映同日信息冲击。
- 后复权价格在研究完成后由供应商生成；内部哈希只能证明本地文件未变，不能证明供应商数据是逐日point-in-time无修订。
- 事件日收盘量和收盘价只有收盘后可知，所以“从事件日收盘到未来”的收益是解释性事件研究，不应被直接包装为同价可执行交易。

## Recommended Future Work

1. 预先定义并添加事件前20/60日收益波动率，避免使用事件后的信息。
2. 获得事件时点行业分类后加入行业固定效应；当前BaoStock行业快照只能诊断集中度。
3. 以CSI300、行业指数或中国Fama–French因子构造异常收益；市场调整结果已作为第一步补充。
4. 对Duration=252的上限堆积做单独指示变量或分层报告，不更改baseline。
