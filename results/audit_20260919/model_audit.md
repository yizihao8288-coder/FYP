# Model Audit

## Existing Result

OLS适合估计条件均值关联，HC3能缓解异方差问题。Model 2含4个斜率参数，R20/R60有效N均为192，参数数量相对样本量不算过多；现有设计矩阵满秩，最大杠杆值约0.092。

但是，193个事件来自160只股票，其中29只股票重复出现，且事件集中在若干年份。HC3不处理同一股票或相近市场日期的误差相关。Petersen关于面板回归标准误的研究说明，在横截面与时间依赖存在时应考虑聚类标准误：https://www.nber.org/papers/w11280

Model 2 R²较低（R20约0.030、R60约0.031），这不使系数无效，但意味着模型不适合高精度预测。

## Potential Improvement

- **Market-adjusted return：需要。** 本次已新增CSI300简单市场调整，降低系统性市场走势的混淆。
- **Industry control：建议，但当前不能严谨执行。** 当前行业快照匹配188/193事件，却不是历史分类；直接当历史行业会引入前视性分类误差。
- **Volatility control：建议。** ATR20或事件前波动率可能同时影响突破阈值、RVOL和未来收益。
- **Fama–French factor：适合作为增强稳健性。** 需要可信的中国市场、规模、价值等日频因子；这将把简单市场调整扩展为风险调整alpha。
- **标准误：优先级高。** 可报告股票聚类；若事件日期聚集明显，进一步报告股票×月份/日期双向聚类或日期层面bootstrap。
- **多重检验：需要披露。** 5个收益窗口、多阈值和多成交量窗口提高偶然显著概率，应强调R20/R60为主要窗口并对其余结果作辅助解释。

## Recommended Future Work

保持当前baseline和HC3主表不变，增设一张稳健性表：同一系数分别用HC3、股票聚类、年份固定效应和CSI300调整收益估计。不要按显著性选择最终规格。
